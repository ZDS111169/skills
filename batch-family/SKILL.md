# 整族批量改

跨产品通用。不绑死某一个仓库名。把「长得一样、只是字段或路由不同」的一家族页面/模块一次改齐。

## 何时用 / 何时不用

| 用户说法 | 行为 |
| --- | --- |
| `批量改` / `批量改此处` / `批量改【主题】` | 整族改。`批量改此处` = 以当前讨论点为**样板**扩到同族，不是只改一个文件 |
| `整族对齐…` / `按批量 Skill 做：…` / `/batch-family` | 同上 |
| `供应商客户一起` / `单据财务同样` / `往来单位同样` / `列表页整族` | 按已知成对/成族关系扩 |
| `单独改` / `单量修改` / `只改…` / `不要整族` | **只改点名处**；若存在对称页，先问一句要不要带，除非用户已禁止 |

未写入上表的近义词（例如「一并改掉」）不保证触发；重要请求请用表内原词。

不要在用户只问「怎么设计批量流程」、没有要改代码时使用本技能。

## 关联文件

| 文件 | 何时用 |
| --- | --- |
| `references/families.md` | 归族拿不准、或要对照通序 ERP 已有成对样例时读。只读这一层 |

无 scripts、无 assets。

## 步骤

1. **归族**  
   根据当前样板文件/截图/口述，判定族名（例如：往来单位弹窗、单据列表引导、MES 某列表筛选）。  
   若拿不准，先读 [references/families.md](references/families.md)，再 Grep/Glob 列出候选路径。

2. **列清单并标例外**  
   写出将改路径。用户已声明的单点例外写进「例外」。结构同、字段不同时列**字段映射**（禁止把 A 的字段名原样贴到 B）。

3. **确认扩散范围（仅必要时）**  
   - 已是批量口令 → 直接按清单改，勿再问「要不要整族」。  
   - 单独改且存在明显对称页 → 问一句；用户说不要带则只改单点。

4. **整族修改**  
   按映射改完清单内文件。优先改共同 mixin/基类/组件；没有共同层再逐文件改。  
   不改：密钥、无关模块、用户划在例外里的路径、未归入本族的页面。

5. **收工回报（固定格式）**

```text
族：<族名>
样板：<文件或简述>
默认改：<路径列表>
例外：<无 / 路径+原因>
已改：<路径列表>
未改及原因：<无 / 说明>
字段映射：<无 / A.x → B.y>
```

## 边界

- 适用于任意工作区（ERP / MES / 小程序 / 网页 / 上位机），以**当前打开的仓库**为准。  
- 不擅自 `git commit` / `push`。  
- 不把「批量改此处」理解成「只改当前一个文件」。  
- description 未列出的口语近义不当作口令。
